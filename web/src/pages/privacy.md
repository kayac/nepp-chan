**第４条（ユーザー関与の方法）**

**(A) Web 公式サイト経由でご利用の場合**

ブラウザのデータ削除機能等により、お客様の端末に保存された識別情報を削除いただくことで、本サービスとの紐付けを即時に消去できます。

削除後、弊社が保有する会話履歴等は、第１条第２項(A) 記載のとおり弊社単独ではお客様を特定できないデータとして扱われ、本サービスの保管期間ポリシーに基づき経過後に自動的に削除されます。

**(B) LINE 公式アカウント経由でご利用の場合**

お客様が LINE 公式アカウント「ねっぷちゃん」を**ブロック**いただくことで、本サービスへの情報送信を停止できます。弊社は、ブロックを検知した時点から 24 時間以内に、当該ユーザーに紐づく情報を弊社サーバから削除いたします。

また、第１１条記載の窓口にご連絡いただくことで、ご自身の個人情報の開示・訂正・追加・削除・利用停止・第三者提供停止を請求いただけます。

**第５条（退会）**

**(A) Web 公式サイト経由でご利用の場合**

ブラウザの匿名のランダム文字列を削除いただくか、本サービスのご利用を停止いただくことで、本サービスとのご関係は終了します。お客様の Web ご利用に係るデータは、第４条(A) のとおり弊社単独で特定不能なデータとして取り扱われ、保管期間経過後に自動的に削除されます。

**(B) LINE 公式アカウント経由でご利用の場合**

ユーザーが本サービスの LINE 公式アカウント「ねっぷちゃん」をブロックいただいた場合、または弊社が本サービスの提供を終了した場合、弊社は当該ユーザーから取得した情報（LINE のユーザー識別子、メッセージ本文、会話履歴、アンケート回答を含みます）を弊社サーバから削除いたします。

ユーザーが LINE 公式アカウントをブロックせずに端末から LINE アプリ自体の利用を停止された場合や端末を交換・廃棄された場合、弊社サーバ上の情報は自動的には削除されません。完全な削除をご希望の場合は、ブロック操作を行っていただくか、第１１条の窓口にご連絡ください。
