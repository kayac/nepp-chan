# 音威富士スキー場

## 2025-2026年シーズン営業予定

## シーズン券

```json
[
  {
    "大人": "17,000円",
    "中学生": "12,200円",
    "小学生": "10,300円"
  }
]
```

- 販売場所: スキー場券売所
- 購入時に必要なもの: 印鑑、写真1枚（縦3cm×横2.3cm）
- 村民には購入補助あり

## スキー場ロッジ

- 食堂・売店は休業中（人員不足のため）
- ロッジ内での飲食は可能

## 宿泊施設

### 青少年宿泊研修施設トムテ

スキー場ロッジ直結の宿泊施設。スキーシーズン以外の宿泊も可能。

- TEL: 01656-5-3157

### 住民保養センター天塩川温泉

大正初期に発見された「常盤鉱泉」という温泉を楽しめる。

- TEL: 01656-5-3330
