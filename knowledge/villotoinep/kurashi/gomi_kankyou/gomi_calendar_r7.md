# 音威子府村 家庭ごみ分別収集カレンダー（令和7年度）

2025年（令和7年）4月から2026年（令和8年）3月まで

## ごみ袋・分別ルール

| ごみの種類 | ごみ袋 |
|---|---|
| 紙製の容器包装・その他紙 | 市販の黄色の半透明のごみ袋 |
| プラスチック製の容器包装 | 市販の白色の半透明のごみ袋又はレジ袋 |
| ペットボトル | 市販の白色の半透明のごみ袋 |
| カン・ビン | それぞれ村指定の専用ごみ袋 |
| 生ごみ | 村指定の専用ごみ袋 |
| 炭化ごみ | 村指定の専用ごみ袋 |
| 一般ごみ | 村指定の専用ごみ袋 |
| 粗大ごみ | 役場で処理券をご購入ください |
| スプレー缶・ライター | 使い切って、穴を空けないでください |

※青・黒い袋・段ボール等を使用している場合は回収しません

## 定期収集パターン

- **火曜**: 生ごみ・炭化ごみ（毎週）+ 隔週交互で以下を追加
  - スプレー缶・ライター（隔週）
  - ダンボール・新聞雑誌・蛍光管（隔週、上記と交互）
  - ※月をまたいで連続的に交互するため、月の第何週かではなく前週との交互で決まる
- **水曜**: 紙製容器包装・その他紙（毎週）
- **木曜**: プラスチック製の容器包装（毎週）
- **金曜**: 生ごみ・炭化ごみ（毎週）+ 隔週交互で以下を追加
  - カン・ビン（隔週）
  - ペットボトル（隔週、上記と交互）
  - ※月をまたいで連続的に交互するため、月の第何週かではなく前週との交互で決まる
- **土曜**: 一般ごみ（毎週）
  - 粗大ごみ・使用済み小型家電: 基本は第1土曜（ただし月によって異なる場合あり）
  - 12月: 粗大ごみの収集なし
  - 1月: 第1土曜が年末年始休みのため粗大ごみの収集なし
  - 3月: 第3土曜（21日）・第4土曜（28日）に粗大ごみを収集（第1土曜は収集なし）

※日曜・月曜は収集なし
※年末年始（12月31日〜1月3日）は収集休み
※実際の収集日は各月の表を確認してください
