# 各種年金手続き

国民年金に関する各種手続きについてご案内します。

---

## 届出が必要なとき

### 20歳になったとき

20歳になると国民年金に加入する届出が必要です。届出後、年金手帳が交付されます。

**届出に必要なもの**:
- 届出書（役場窓口にあります）
- 印鑑

### 就職・退職したとき

```json
[
  {
    "届出内容": "就職したとき（厚生年金加入）",
    "届出先": "勤務先で手続き"
  },
  {
    "届出内容": "退職したとき（厚生年金脱退）",
    "届出先": "役場窓口で届出"
  }
]
```

**退職時に必要なもの**:
- 届出書
- 年金手帳
- 印鑑
- 退職日がわかる書類（離職票など）

### 氏名・住所が変わったとき

氏名や住所が変わったときは届出が必要です。

**届出に必要なもの**:
- 届出書
- 年金手帳
- 印鑑

### 配偶者の扶養に入ったとき・はずれたとき

```json
[
  {
    "届出内容": "扶養に入ったとき（第3号被保険者へ）",
    "届出先": "配偶者の勤務先で手続き"
  },
  {
    "届出内容": "扶養からはずれたとき（第1号被保険者へ）",
    "届出先": "役場窓口で届出"
  }
]
```

**扶養からはずれたとき必要なもの**:
- 届出書
- 年金手帳
- 印鑑
- 扶養からはずれた日がわかる書類

### 年金手帳を紛失したとき

年金手帳を紛失した場合は、再交付の届出ができます。

**届出に必要なもの**:
- 届出書
- 印鑑
- 本人確認書類
