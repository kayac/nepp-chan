# 国民健康保険税

国民健康保険税は、国民健康保険に加入している世帯に課される税金です。

---

## 納税義務者

国民健康保険に加入している世帯の**世帯主**が納税義務者となります。

> **注意**: 世帯主が国保に加入していなくても、世帯員に加入者がいる場合は世帯主に課税されます。

---

## 税額の算定

国民健康保険税は、以下の区分ごとに算定されます。

### 医療分

```json
[
  {
    "算定区分": "所得割",
    "内容": "加入者の所得に応じた額"
  },
  {
    "算定区分": "均等割",
    "内容": "加入者1人あたりの額"
  },
  {
    "算定区分": "平等割",
    "内容": "1世帯あたりの額"
  }
]
```

### 後期高齢者支援金分

```json
[
  {
    "算定区分": "所得割",
    "内容": "加入者の所得に応じた額"
  },
  {
    "算定区分": "均等割",
    "内容": "加入者1人あたりの額"
  },
  {
    "算定区分": "平等割",
    "内容": "1世帯あたりの額"
  }
]
```

### 介護分（40歳以上65歳未満の方）

```json
[
  {
    "算定区分": "所得割",
    "内容": "加入者の所得に応じた額"
  },
  {
    "算定区分": "均等割",
    "内容": "加入者1人あたりの額"
  },
  {
    "算定区分": "平等割",
    "内容": "1世帯あたりの額"
  }
]
```

---

## 納期

年8回（7月〜翌年2月）

---

## 軽減制度

世帯の所得に応じて、均等割・平等割が軽減される制度があります。

```json
[
  {
    "軽減割合": "7割軽減",
    "対象": "世帯の総所得金額が一定基準以下"
  },
  {
    "軽減割合": "5割軽減",
    "対象": "世帯の総所得金額が一定基準以下"
  },
  {
    "軽減割合": "2割軽減",
    "対象": "世帯の総所得金額が一定基準以下"
  }
]
```
